## ЖЁСТКИЕ ТРЕБОВАНИЯ К СООТВЕТСТВИЮ

### КОНФИГ БЕКТЕСТЕРА = КОНФИГ ПРОД БОТА

**ВСЕ параметры из прод конфига ДОЛЖНЫ быть в бектестере:**

1. **[strategy]** - ВСЕ фильтры сигналов:
   - side_filter, price_move_mult, min_natr, natr_window
   - max_spike_age_ms, max_entry_distance_pct, entry_window_secs
   - min_pre_vol_mode, min_pre_vol_usd, min_pre_vol_lookback
   - min_pre_vol_multiplier, min_pre_vol_warmup, min_pre_vol_window
   - scan_interval_ms, signal_cooldown_secs
   - **ВСЁ что есть в проде - должно быть в бектестере!**

2. **[trading]** - ВСЕ механизмы:
   - trail_enabled, trail_position_percent, trail_activation_pct, trail_callback_pct
   - tp_position_percent (partial TP!)
   - entry_price_mode, entry_slippage_pct
   - reverse_signal_close_position
   - qty_priority
   - **ВСЁ что есть в проде - должно быть в бектестере!**

3. **ВСЕ дополнительные блоки:**
   - [breakeven] - полностью
   - [smart_profit_lock] - полностью
   - [tape_exhaustion] - полностью
   - [reversal_entry] - полностью
   - [whale_exhaustion] - полностью
   - [natr_filter] - полностью
   - [market_mode] - полностью

### СИМУЛЯЦИЯ = ПРОД ЛОГИКА

**Simulator ОБЯЗАН реализовывать:**
- Trailing stop (если trail_enabled = true)
- Breakeven (если enabled = true)
- Smart Profit Lock (если enabled = true)
- Partial TP (tp_position_percent)
- Все фильтры входа из [strategy]
- Все механизмы выхода из [trading]

**НЕ УПРОЩАТЬ! НЕ ПРОПУСКАТЬ! 1-в-1!**

### ПРОВЕРКА СООТВЕТСТВИЯ

Перед сдачей работы ОБЯЗАТЕЛЬНО:
1. Открыть `config.toml` прод бота
2. Открыть `backtester/config.toml`
3. Сравнить КАЖДЫЙ параметр
4. Убедиться что ВСЕ параметры присутствуют
5. Убедиться что simulator использует ВСЕ механизмы
